# Responsive Device Previewer

See one URL across every screen at once: iPhones, Android phones, tablets, laptops and desktops.

**Live:** https://jonnyshan.github.io/device-previewer/

- **★ Most popular phones** shows only the top 6 phones in use in Australia & NZ
- **▭ URL bar** adds Safari/Chrome bars to every phone and tablet and shows how much screen is left
- **Chrome vs Safari** row compares each browser's visible area
- Rotate, zoom, custom sizes, and **Copy link** to share an exact setup

Single HTML file, no build step. Sites that block embedding (Google, banks, etc.) show blank; use ↗ to open them in a new tab.
